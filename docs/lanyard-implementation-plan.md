# 경력 카드 초기 화면

## 확정한 UX

첫 화면은 아하랩스, 티맥스 클라우드, 개인 프로젝트 세 카드다. 캐러셀은 사용하지 않는다. 회사 카드 앞면에는 회사명, Frontend 연구원, 재직 기간을 표시한다. 개인 카드는 제목과 작업 성격만 표시하고 확인되지 않은 날짜는 만들지 않는다.

카드를 80px 이상 아래로 당긴 뒤 놓으면 같은 페이지에서 선택한 카드와 상세를 표시한다. 짧게 당기면 복귀한다. 112px까지 이동을 제한한다. pointercancel, capture loss, Escape, 창 blur, 화면 이탈은 상세 진입 없이 취소한다. 클릭/Enter 및 별도 링크로도 같은 상세를 연다. 상세 제목으로 포커스를 옮기고, “경력으로 돌아가기”는 선택했던 카드로 포커스를 복귀시킨다.

## 공통 컴포넌트 계약

`Lanyard`는 `title`, `role`, 선택적 `period`, 선택적 `design`, `href`, `onOpen`, `motionEnabled`, `id`를 받는다. 상세 데이터는 카드와 분리한다.

`design`은 줄 바탕색/테두리색, 카드 바탕색/배경 이미지/글자색/하단 두 색과 비율을 받는다. 이미지와 텍스트를 분리해 배경만 교체할 수 있다. 입력하지 않은 줄 테두리는 줄 바탕색으로 채운다. 카드 전체 디자인을 생략해도 기본 디자인을 표시한다.

모든 카드 크기는 224×304px, 줄 너비는 24px, 양쪽 테두리는 각각 2px이다. 데스크톱과 모바일, 선택한 카드 상세에서도 공통 크기를 유지하며 카드별 크기 옵션은 제공하지 않는다. 좁은 화면에서는 세 카드를 세로로 배치하고 카드 바깥 영역으로 스크롤한다.

티맥스는 제공된 사진을 참고해 흰 바탕, 하단 빨강(#bd2839) 70%와 파랑(#183b80) 30%, 파란 줄과 빨간 테두리를 적용한다. 사진 자체를 게시하거나 인물 사진을 추출하지 않는다. 아하랩스와 개인 카드는 기본 디자인으로 시작한다.

## 구현 구조

- `data/portfolio.ts`: 경력, 개인 작업, 관련 Case Study ID와 디자인
- `hero/badge-design.ts`: 디자인 타입, 기본값, 공통 치수
- `hero/StaticBadgeFallback.tsx`: 모든 환경에서 동일하게 사용하는 HTML 카드 앞면
- `hero/Lanyard.tsx`: 포인터 상태, 환경 판단, 정적 줄, 지연 로딩/실패 처리
- `hero/LanyardScene.tsx`: R3F/Rapier의 고정점+줄 3마디+카드, rope/spherical joint, DOM 카드 위치 동기화
- `hero/Hero.tsx`: 세 카드 선택과 상세 전환, 포커스 복귀

텍스트는 Canvas에 굽지 않고 DOM으로 유지한다. 데스크톱 960px 이상, fine pointer, 모션 감소 미사용 시에만 3D를 import한다. 카드별 고정 크기 독립 장면으로 구성해 해상도/물리를 격리한다. DPR 상한 1.5, 물리 timestep 1/60, 뷰포트 이탈/백그라운드에서는 물리 및 렌더링을 멈춘다.

줄은 Catmull–Rom 곡선을 재사용하고 두 개의 고정 버퍼 리본으로 그린다. 매 프레임 벡터/배열 생성이나 React state 갱신이 없고, 2px 줄 테두리를 유지한다. 정적 카드도 포인터 당기기와 접근 가능한 링크를 제공한다. WebGL 실패/컨텍스트 유실/15초 로딩 실패 시 정적 동작으로 전환한다.

## 검증

Astro check, Vitest, production build 및 Playwright에서 크기·배색, 키보드 및 포커스, 임계값, 취소, reduced-motion, WebGL 실패, JavaScript 없는 링크, 물리 복귀 및 기존 프로젝트 탐색을 검증한다. 브라우저 검수는 데스크톱/모바일에서 시행한다.

## 체크포인트 — 초기 경력 카드 경험

상태: 구현 및 자동 검증 완료, 사용자 확인 대기.

- 아하랩스, 티맥스 클라우드, 개인 프로젝트 카드 세 장과 공통 크기를 적용했다.
- 티맥스 카드에 제공된 사원증의 흰 바탕, 파란 줄·빨간 테두리, 하단 빨강 70%·파랑 30% 배색을 반영했다.
- 디자인이 없는 카드에는 공통 기본 디자인과 줄 색상을 적용했다.
- 클릭, Enter, 아래로 당기기 임계값으로 상세를 열고 “경력으로 돌아가기”로 선택 카드에 포커스를 복귀시킨다.
- WebGL 미지원·초기화 실패·컨텍스트 유실, 모션 감소, 모바일, JavaScript 비활성 환경에서 정적 카드와 링크를 유지한다.
- `npm run verify`: Astro 오류 0건, Vitest 7개 통과, 정적 페이지 10개 빌드 완료.
- `npm run test:e2e`: 28개 통과, 모바일에서 실행할 필요가 없는 데스크톱 물리 전용 2개 제외.
- 디자인 검사: 지적 사항 0건.
- 의존성 감사: 알려진 취약점 0건.

다음 시작점: 사용자 확인 후 실제 사용감에 따른 카드 간격·당김 임계값·물리 감쇠만 조정한다. 새로운 콘텐츠나 시각 체계 변경은 별도 마일스톤으로 분리한다.

## 범위

기존 프로젝트 탭, 상세 페이지 URL, about/contact/engineering 페이지를 유지한다. 원본 brief 수치 후보는 현재 MDX와 달라 게시하지 않는다. 개인 작업은 근거가 있는 포트폴리오 구현 기록에 연결하며 새 사이드 프로젝트를 만들어 넣지 않는다.
